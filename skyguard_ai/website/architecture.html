Ensemble Model Weights

Rule Engine
40%

12 physics rules. Zero-latency, 100% transparent. Catches out-of-range, spikes, frozen sensors definitively.

✓ No false negatives on OOR
✗ Misses subtle drift
Isolation Forest
40%

Unsupervised multivariate detector. 200 trees on clean data. Excels at multivariate inconsistencies invisible to univariate checks.

✓ Catches multivariate
✗ Higher false positives
Statistical Z-Score
20%

Rolling 3-hr and 12-hr Z-scores. Lightweight, catches slow calibration drift and seasonal deviations.

✓ Catches slow drift
✗ Seasonal blind spots
RandomForest (+)
Bonus

Supervised component when labeled data available. 300 trees, balanced class weights. Provides SHAP values for full explainability.

✓ SHAP explainability
✗ Needs labeled data
